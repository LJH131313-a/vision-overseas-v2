# 远见·企业出海助手

面向中国小家电出海业务的合规准备工作台：把**企业研究档案、产品与目标市场登记、法规合规初筛、HS 候选与税费阶段测算、政策新闻雷达、千问辅助建议**连接成一条**向导主线**，产出一份可追溯的综合报告。

纯静态网站（无后端、无数据库、无内置密钥），可直接部署在 GitHub Pages；本机双击 `index.html` 也能使用核心功能。

## 使用动线（左侧栏向导）

1. **项目与产品**：可选从企业案例一键带入（小熊电器 / 石头科技公开研究档案，含待核实参数与研究路线声明；国内型号不自动当作出口型号）；登记项目、目的地与品类。目的地按「可复算税费 / 可条件初筛 / 仅法规资料」三档分组；品类卡片直接显示当前目的地的支持度。**关键事实按需追问**：只显示影响当前判断的问题（引擎实时反推），其余参数收入选填折叠区。
2. **合规初筛**：实时计算，结果分为可能适用 / 待补事实（回答即重算）/ 单条规则不适用（含原因）/ 待规则核验（索引级法规仅导航），并生成办理行动、材料清单与责任建议；覆盖不足显示明确缺口。
3. **HS 与税费**：HS 候选方向（非海关最终归类，SG/AU 含电吹风/电熨斗扩展候选）；SG/AU 已核税费画像逐行输出税基、税率、税额、币种与承担方；马来西亚、德国显示研究**变量计算式模板**（税率未核实不代入数值）；并内置 19 条**税则知识库**（税种/税基/公式/适用前提/缺失处理/依据）与**贸易术语承担矩阵**；条件不足时完整总额保持不可用并说明阻断原因。
4. **新闻雷达（可选）**：政府官方 RSS/Atom 定时快照（北京时间约 09:17 / 17:17），市场/主题/关键词/当前项目筛选，可勾选进入建议任务。
5. **千问建议**：一键调用千问 API（自带 DashScope 密钥，仅存本机浏览器，不进代码与仓库）自动分析并保存；也可用手动闭环（生成任务 → 复制 → 粘贴回复）。回复严格标记「API 调用 / 人工导入」，与本地规则提示区分；输入变化后自动标「需要重新分析」。
6. **综合报告**：汇总全部结论，每条可追溯来源；打印 / 导出 PDF、导出项目 JSON（不含密钥）、报告快照与历史结果标记；本机保存（单机，非多人协作）。

侧栏各步骤带完成状态点；顶栏「数据说明」查看数据来源、覆盖等级与未完成事项。

## 目录结构

```
├── index.html              # 主页面（向导主线）
├── css/styles.css          # 样式（青绿主色 + 侧栏导航 + 渐变 hero）
├── js/engine.js            # 三值规则引擎 + SG/AU 税费引擎（语义与原始数据包一致）
├── js/app.js               # 向导模块、按需追问、项目状态（localStorage 本机保存）
├── data/vo-data.js|json    # 整合数据包（由 build/build-data.mjs 生成）
├── data/news.js|json       # 新闻快照（由 tools/collect_news.py 定时重建）
├── news/feeds.json         # 新闻 RSS/Atom 来源配置
├── tools/collect_news.py   # 新闻采集与合并（Python 标准库）
├── tools/rebuild_news_js.mjs  # 无 Python 环境时重建 news.js
├── build/build-data.mjs    # 从原始团队交付物生成数据包的构建脚本
├── .github/workflows/      # 定时采集 + Pages 部署工作流
├── tests/                  # 引擎回归（208 断言）、DOM 冒烟（61 断言）、静态资源（25 断言）
└── docs/                   # 中文文档（启动发布、产品介绍、演示脚本、数据来源、测试与验收记录）
```
