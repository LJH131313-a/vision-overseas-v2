# 产品介绍与团队分工

## 一、作品定位

**远见·企业出海助手**面向中国小家电企业（案例取自小熊电器、石头科技的公开资料）的出海合规准备场景，把散落在各处的企业研究、产品参数、法规条款、税费画像、官方公告连接成一个**可演示、可复算、可追溯**的工作台，最终产出一份有来源、有条件、有行动清单的综合建议报告。

核心设计原则：

- **不确定就如实说不确定**：缺失事实保持「待补事实」，不按「否」处理；未知税率、贸易救济不按零处理；覆盖不足的组合明确显示缺口，不输出虚假完整结论。
- **候选不冒充结论**：HS 只作候选方向；官方新闻不自动等于已生效法规；规则提示与人工导入的千问回复明确分开标注。
- **千问辅助双模式**：方式一为 API 直连——页面内填入用户自己的阿里云百炼（DashScope）API Key（仅存本机浏览器 localStorage，不进入页面代码、仓库或导出文件），一键完成「生成任务 → 调用模型 → 回复自动保存」，支持大陆/国际站端点、四种预设模型与自定义模型/代理地址，带连通测试与具体失败提示；方式二为无密钥的手动闭环。两种方式产出的回复分别标记「API 调用（含模型名）」与「人工导入」，与本地规则提示严格区分，输入指纹变化后自动标记需要重新分析。
- **每条结论可追溯**：规则 ID、条款定位、来源链接、核验日期、输入指纹贯穿全部模块。
- **本地闭环、无密钥**：千问辅助采用「生成任务 → 人工交给千问办公 → 粘贴回复」的手动闭环，不调用付费 API，页面中没有任何密钥或虚构的模型输出。

## 四、典型使用流程

企业档案（选案例带入）→ 产品与市场登记（动态问题+不确定项）→ 合规初筛（四类结论+行动材料）→ HS 候选与税费（有画像复算、无画像显示缺口）→ 新闻雷达（筛选勾选）→ 千问辅助（任务→粘贴回复）→ 综合报告（打印/导出/快照）。

## 五、适用范围与免责

本作品用于**合规准备与资料组织**：规则匹配、HS 候选、税费分项均不构成正式合规、认证、法律、税务、原产资格或海关归类结论；最终认定以主管机关、认证机构、律师、税务顾问与海关为准。数据快照 2026-11-04，覆盖范围与未完成事项见「数据说明」页与《数据来源与核验状态》文档。
